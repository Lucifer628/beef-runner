# beef-runner
BeEF-Runner is a Termux-optimized installer and launcher for the BeEF (Browser Exploitation Framework). It automates dependency resolution, system configuration, and IP detection — enabling security professionals to deploy and run BeEF on Android devices with a single command. No manual setup required.
# usage
git clone https://github.com/Lucifer628/beef-runner.git
chmod +x beef-runner
./beef-runner
# or
bash beef-runner
